# Voice rules

## The voice

Plain, direct, specific. Write to one reader, in the second person. Use the active voice and a
concrete noun. Put one idea in each sentence.

## Sentence rules

1. Subject, verb, object, in that order. If a sentence needs a second reading, split it.
2. Prefer the short word: `use` over `utilise`, `help` over `facilitate`, `buy` over `purchase` when the buyer is a person.
3. Prefer a verb to a noun built from it: `decide` over `make a decision`, `apply` over `submission of an application`.
4. Cut intensifiers: `very`, `really`, `incredibly`, `highly`, `extremely`. The fact carries the weight.
5. One qualifier per claim at most. Two qualifiers in a sentence means the claim is not ready.
6. Numbers as digits, with the unit: `3 days`, `12 percent`, `USD 4,200`.
7. Dates in prose as `1 November 2026`. ISO dates are for tables and logs.
8. No exclamation marks. No rhetorical question as an opening.
9. No sentence longer than 25 words in a reply, 35 in a brief.
10. `We` means the organisation. An agent never writes `we` to mean itself.

## Banned phrases, with replacements

| Banned | Replace with |
| --- | --- |
| in today's fast-paced world | delete the sentence |
| it is important to note that | delete the phrase |
| needless to say | delete the phrase |
| at the end of the day | delete the phrase |
| delve into | look at, read, check |
| leverage (as a verb) | use |
| utilise | use |
| seamless | works without a step, or name the step |
| cutting-edge, state of the art | name the version or the date |
| world-class, best-in-class | name the measurement |
| revolutionary, game-changing | name what changed and for whom |
| empower | let, help, give |
| robust (outside engineering) | name the failure it survives |
| synergy, ecosystem, solution (alone) | name the thing |
| unlock the power of | use |
| reach out | contact, email, call |
| circle back | follow up on |
| touch base | meet, or ask |
| please don't hesitate to | delete the phrase |
| we are excited to announce | say what shipped and when |
| guaranteed, always, never fails | the measured claim, with its condition |

## Structure

- First line: the news or the ask.
- Next: the reason, in one or two sentences.
- Then: the detail the reader needs to act, as a short list or a table.
- Last line: the next step, with an owner and a date when one exists.
- No preamble, no restatement of the request, no closing courtesy line in a brief.

## Claims

- A claim that needs a source keeps its citation, and the citation stays next to the claim.
- A comparison names the baseline and the date of the measurement.
- A promise names the condition under which it holds.
- A customer name, quote, or logo needs written approval before it appears. If approval is not in hand, write the sentence without it.
